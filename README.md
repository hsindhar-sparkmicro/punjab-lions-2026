# Punjab Lions CC · 2026 Season

A one-page site celebrating Punjab Lions Cricket Club's 2026 season in Cricket Quebec: the squad, a highlight reel, Lions Moments, Lions on the world stage, and the numbers for every team.

- **Live:** https://hsindhar-sparkmicro.github.io/punjab-lions-2026/
- **Data:** CricClubs (Cricket Quebec) 2026 team, player and points-table records.
- **Photos and videos:** courtesy of Punjab Lions / [@punjablions.cc](https://www.instagram.com/punjablions.cc/). Player portraits are CricClubs profile pictures.

Static HTML/CSS/JS (Chart.js bundled in `vendor/`); no build step. Served by GitHub Pages.
